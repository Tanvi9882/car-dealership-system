# 🚗 DrivePulse - Car Dealership Inventory System

DrivePulse is a modern, high-performance **Car Dealership Inventory Management System** built with **FastAPI**, **SQLite**, **Pytest**, **React (Vite)**, and **Tailwind CSS**.

It provides complete JWT-authenticated role-based access control (Users & Admins), a full inventory CRUD suite, vehicle purchase/restock workflows, category price insights, natural language AI smart search, and an interactive showroom featuring the **Mahindra SUV Fleet** (`XUV 3XO`, `Bolero`, `Thar`, `Scorpio Classic`, `BE 6`).

---

## 📐 System Architecture & Stack

- **Backend**: Python 3.13, FastAPI, SQLAlchemy, SQLite, Pydantic v2, PyJWT, Passlib (Bcrypt).
- **Testing (TDD)**: Pytest, TestClient (**14 / 14 tests passing**).
- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React Icons.
- **Database**: SQLite (`car_dealership.db`).

## 🖼️ Application Features & Screenshots

### 1. Showroom Dashboard & Brand Filtering
- **Brand Selector**: 1-click pills to filter by `Mahindra`, `Kia`, `Skoda`, or `All`.
- **Specs Badge**: Displays Fuel Type, Transmission, and Seating Capacity (`4`, `5`, `7`, `7 / 9`).
- **Ex-Showroom Price Range**: Formatted Indian Lakh prices (e.g. `₹7.54 – ₹15.79 lakh`).

### 2. Vehicle Purchase & Stock Control
- Interactive **"Purchase Vehicle"** button.
- Automatically disables with *"Out of Stock"* badge when quantity reaching `0`.

### 3. AI Smart Search & Recommendations
- **Natural Language Search**: Try queries like *"Mahindra SUV under 15 lakh"*, *"Electric cars"*, *"Luxury sedan"*.
- **Category Insights**: Shows whether a car is `Good Value` (15%+ below category average) or `Premium`.

## ⚡ API Endpoints Summary

### 🔐 Authentication (`/api/auth`)
- `POST /api/auth/register` - Register a new User or Admin.
- `POST /api/auth/login` - Authenticate user & receive JWT Bearer Token.

### 🚘 Vehicles (`/api/vehicles`)
- `GET /api/vehicles` - List all available showroom vehicles.
- `GET /api/vehicles/search` - Filter vehicles by make, model, category, or min/max price.
- `GET /api/vehicles/smart-search` - AI Natural Language Search.
- `GET /api/vehicles/{id}` - Get detailed view & price insights.
- `GET /api/vehicles/{id}/recommendations` - Get AI recommendations (*"Customers who viewed this car may also like..."*).
- `POST /api/vehicles` - **(Admin Only)** Add a new vehicle.
- `PUT /api/vehicles/{id}` - **(Admin Only)** Update existing vehicle specifications.
- `DELETE /api/vehicles/{id}` - **(Admin Only)** Delete a vehicle from inventory.

### 📦 Inventory Workflow (`/api/vehicles`)
- `POST /api/vehicles/{id}/purchase` - **(User/Auth)** Purchase vehicle (decrements stock by 1).
- `POST /api/vehicles/{id}/restock` - **(Admin Only)** Restock vehicle inventory by specified amount.

## 🚀 Local Setup & Installation

### 1. Backend Setup
```bash
cd backend
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
- API Docs (Swagger): `http://localhost:8000/docs`

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
- Frontend App: `http://localhost:5173`
